# EuroCart kit

Starter material for an Elephant Carpaccio workshop built around **EuroCart**: a checkout page
for a Dutch web shop selling to six European countries. Catalogue prices are in EUR excluding VAT.

Using this material is optional. Teams are free to pick any language, framework or tooling.

| Directory | What |
|---|---|
| [`skeleton-spring/`](skeleton-spring/) | Spring Boot 4.1 / Java 21 skeleton: product catalogue (51 products), in-memory cart, subtotal excl. VAT, static HTML front-end. |
